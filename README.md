# snp — Yasin Developer Portfolio

An interactive personal portfolio for Yasin, built around real GitHub projects and small web experiments.

## Included

- Responsive developer portfolio
- All current GitHub repositories shown as project cards
- Search and category filtering
- GitHub and live-demo links where available
- Dark/light theme with persistence
- Interactive developer lab
- Accessible modal project details
- SEO-friendly metadata
- No build step required: plain HTML, CSS and JavaScript

## GitHub Pages

This repository is designed to run directly from the `main` branch root with GitHub Pages.
